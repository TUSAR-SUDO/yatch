Project Overview

YORCH is a premium, cinematic single-page web application designed for a private luxury yacht club. The project demonstrates advanced frontend engineering through its sophisticated animation architecture, custom glassmorphism design system, and immersive video-driven user experience.

Built entirely from scratch using React 19 and TypeScript, the application features full-screen cinematic video backgrounds, GSAP-powered theatrical navigation, Framer Motion scroll-triggered animations, and a custom cursor-following water ripple effect — all wrapped in a meticulously crafted editorial design language.

Architecture Decisions

  • No Router: SPA with overlay-based page navigation via boolean state — optimal for a single-page luxury brochure experience
  • Dual Animation Libraries: Framer Motion for declarative scroll-linked animations; GSAP for complex imperative timeline choreography where fine-grained control is required
  • State at Root: Centralized state management via React useState at App level — avoids unnecessary complexity from external state libraries
  • CSS Custom Properties: Extensive design token system via :root variables for consistent theming across light and dark contexts

Component Hierarchy

The App.tsx root component manages 6 boolean states controlling the visibility of the menu, fleet overlay, and 4 page overlays. The layout uses a fixed video background at z-index 0, a 100vh spacer div, and scrollable content sections stacked sequentially above it — creating a parallax-like scroll-past-hero effect without actual parallax computation.

Key Features & Interactions

🎬 Cinematic Video Backgrounds

Full-screen looping video backgrounds across Hero, Manifesto, Experiences, Academy, and Footer sections. Hero video stays fixed while content scrolls past, with 100px blur transition when fleet overlay opens.

🧊 4-Tier Glassmorphism

Custom frosted-glass effect system with progressive blur, saturation, and brightness levels. Each tier includes inner box-shadows and semi-transparent borders for photorealistic depth.

⚡ Staggered Text Reveals

Hero headline uses Framer Motion container/children variants with staggerChildren: 0.12 and custom luxury easing. Each of 4 lines slides up from y:40 with opacity fade.

🌊 Cursor Ripple Trail

Custom canvas-like effect using 80-element object pool with requestAnimationFrame. SVG feTurbulence + feDisplacementMap filters create liquid water distortion at cursor position.

GSAP Staggered Menu — Animation Timeline

The most complex animation in the project. A choreographed multi-stage open sequence:

Stage 1 — Label Cycle
Menu toggle text cycles from "MENU" to "CLOSE" with y-translation. Icon rotates 225°.
Stage 2 — Prelayer Entrance
Two colored layers (navy #1c3557, then blue #2d5080) slide in from the right with 80ms stagger.
Stage 3 — Panel Slide
Main content panel slides in from right at 150ms offset with power4 easing.
Stage 4 — Prelayer Sweep
Both prelayers sweep out to the left, creating a theatrical wipe-reveal effect.
Stage 5 — Content Stagger
6 nav items stagger in from x:40 with 60ms delay between each. Social links fade up from below.

Additional Interactions

  • Fleet Overlay Triptych: Three yacht panels slide up simultaneously, each filling exactly 1/3 of the viewport with staggered delay
  • Scroll-Snap Testimonials: Horizontal card rail with CSS scroll-snap-type for controlled card-by-card browsing
  • Animated Progress Bars: Academy module completion bars animate from 0 to target width on scroll-into-view
  • Spec Drawer: Right-side sliding panel with AnimatePresence for yacht specification deep-dives
  • FAQ Accordion: Single-open pattern with arrow rotation and height/opacity animation
  • Yacht Card Hover: Video zoom scale(1.04) on card hover via CSS transition

Technical Highlights

Performance Optimizations

  • Passive scroll listeners — all scroll handlers registered with { passive: true } to avoid jank
  • One-time animations — viewport={{ once: true }} on all scroll-triggered Framer Motion animations
  • GSAP timeline cleanup — timeline.kill() called before every new animation to prevent competing timelines
  • Object pooling — RippleTrail pre-allocates 80 DOM elements and reuses them instead of creating/destroying
  • Direct DOM manipulation — RippleTrail bypasses React rendering entirely, using requestAnimationFrame for 60fps cursor tracking
  • Mobile-safe video — all video elements use muted + playsInline + autoPlay for cross-device autoplay

Type Safety

  • Strongly typed data models for yachts (Yacht, YachtSpec, YachtSpecCategory) and testimonials (Testimonial)
  • Typed component props with explicit interfaces for all inter-component contracts
  • TypeScript strict mode enabled via tsconfig.json
  • Typed GSAP timeline refs: useRef<gsap.core.Timeline | null>

Creative Engineering

💧 SVG Liquid Distortion

RippleTrail uses an SVG filter pipeline: feTurbulence generates Perlin noise, feDisplacementMap applies it as a displacement map, creating realistic water-like distortion at the cursor.

🎭 Prelayer Wipe Reveal

The menu's two colored prelayers create a theatrical curtain-reveal effect — they slide in from the right, then sweep out to the left as the content panel settles behind them.

🔭 Fixed Hero Parallax

The hero video stays position:fixed while a 100vh spacer allows content to scroll over it — achieving a parallax effect without any scroll computation or transform overhead.

📐 Fluid Design Tokens

Every dimension uses clamp() — from font sizes (48px → 130px) to padding (24px → 96px) to the menu width (280px → 440px) — ensuring pixel-perfect scaling across all viewports.
